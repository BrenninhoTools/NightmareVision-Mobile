# NightmareVision Mobile V3

## New
- Hitbox Custom menu with a live preview of the hitbox
- Import Hitbox Image to use any image from your device as the hitbox
- RGB Hitbox to change the color of each lane
- Hitbox Alpha to set how visible the hitbox is
- Reset Hitbox to go back to the default hitbox
- New hitbox modes: Triangle and Double D-Pad
- D-Pad Left and D-Pad Right modes made with the official note assets
- Arrows mode with the notes split in pairs

## Improved
- Back button on every editor, at the bottom right
- Faster asset extraction on Android, and updates only copy the files that changed
- Better touch input and haptics
- Faster iOS builds

## Downloads
- Android: `NightmareVision-Android.apk`
- iOS: `NightmareVision-iOS.ipa` (unsigned, install with your own signing tool)
