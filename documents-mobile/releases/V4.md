# NightmareVision Mobile V4

## New
- Circle hitbox mode
- Battery Saver with Off, Auto and On, plus a battery level for Auto
- Screenshot Button on Android: tap to save to the gallery, hold to share
- Ads on the menus, the pause menu and after songs, with an Ad Break option to play without ads for 30 minutes
- Upgrade in the main menu removes all ads for free
- Restore Purchases and Rate the Game in Mobile Options
- Folder button in the main menu to open the game files when Storage Type is Data
- Compressed Textures option with ASTC support

## Improved
- Stronger and smoother haptics, with Haptics Type and Haptics Intensity up to 5.0
- Haptics on sustains and on stage events like the Philly train, the Limo cars and the Spooky thunder
- New virtual pad on every editor, placed away from the grid
- Smoother touch scrolling, a smaller touch cursor and a Full screen style that fills the screen
- Faster asset extraction on Android
- Faster Android and iOS builds

## Downloads
- Android: `NightmareVision-Android.apk`
- iOS: `NightmareVision-iOS.ipa` (unsigned, install with your own signing tool)
